Mobile App Development

Toda aplicação tem múltiplas telas a serem exibidas. E para isso, é utilizado o recurso de
navegação.
No React Native existe a biblioteca React Navigation que atende esse próposito.
É uma biblioteca de terceiros, ou seja, não foi criada pelo time do React, mas é oficialmente sugerida por eles. Eles também sugerem a React Native Navigation, mas é recomendada para casos mais avançados de uso.

Para instalar a React Navigation, dentro do diretório do seu projeto basta rodar o
comando:
npm install @react-navigation/native

Para funcionar corretamente no Android, deve-se instalar mais duas bibliotecas:
npm install react-native-screens react-native-safe-area-context

Se é um projeto feito com o Expo:
npx expo install react-native-screens react-native-safe-area-context

Para a navegação funcionar no iOS, rode o seguinte comando dentro da pasta do projeto:
npx pod-install ios
Ele vai realizar a instalação de componentes necessários dentro da estrutura do projeto do iOS que o React Navigation necessita para funcionar corretamente.

No Android, ainda é necessário alterar um arquivo Java para funcionar corretamente.
Na estrutura do seu projeto, localize o arquivo no caminho:
android/app/src/main/java/com/<nome do seu projeto>/MainActivity.kt
Dentro desse arquivo, a primeira deve ser algo do tipo:

Java
1
package com.exemplo;

Após essa linha, coloque a linha:

Java
1
import android.os.Bundle;

Ainda no arquivo MainActivity.kt, dentro da classe MainActivity vai ter um metódo chamado getMainComponentName. Após esse metódo, adicionar o metódo onCreate, ficando igual conforme código a seguir:

Feito todos os procedimentos, sua aplicação está pronta para utilizar a biblioteca. O seu arquivo App.tsx deverá importar o NavigationContainer e englobar toda sua aplicação dentro dele. Exemplo:

TypeScript
12345678910111213
import React from 'react';

import { NavigationContainer } from '@react-navigation/native';

function App(): React.JSX.Element {
  return (
    <NavigationContainer>
      {/* Código da sua aplicação vai aqui dentro */}
    </NavigationContainer>
  );
}

export default App;

Por fim, adicione mais uma biblioteca para conseguir criar uma pilha de navegação:
npm install @react-navigation/native-stack

Ainda seguindo a estrutura anterior, dentro do seu NavigationContainer, deve-se criar seu Stack (pilha) de navegação. Para isso, precisa realizar o import do
createNativeStackNavigator. E dentro dele, basta adicionar as telas.

TypeScript
12345678910111213
import { createNativeStackNavigator } from '@react-navigation/native-stack';

const Stack = createNativeStackNavigator();

function App() {
  return (
    <NavigationContainer>
      <Stack.Navigator>
        <Stack.Screen name="home" component={Home} />
      </Stack.Navigator>
    </NavigationContainer>
  );
}

Cada Stack.Screen é uma tela que sua aplicação vai conter e pode ser utilizada na sua pilha de navegação. A propriedade name é uma identificação única, que é utilizada para chamar a tela. A propriedade component determina o que vai ser renderizado.
A ordem de um Stack.Screen é relevante apenas para determinar qual será a primeira tela exibida quando o Stack.Navigator for renderizado. Tirando isso, a ordem das telas pode ser aleatória, visto que pelo código que você controla a navegação.

E como navegamos de uma tela para outra?
Supondo que sua aplicação tenha uma tela de Login que vai pra uma tela de detalhes.
O componente de Login tem o seguinte código:

TypeScript
123456789101112131415
import { Button, Text, TextInput, ScrollView } from 'react-native';

const Login = () => {
  return (
    <ScrollView>
      <Text>User</Text>
      <TextInput placeholder="email" keyboardType="email-address" />
      <Text>Password</Text>
      <TextInput placeholder="password" secureTextEntry={true} />
      <Button title="Login" />
    </ScrollView>
  );
};

export default Login;

Tela de detalhes:

TypeScript
123456789101112
import { View, Text, Button } from 'react-native';

const Details = () => {
  return (
    <View>
      <Text>Details</Text>
      <Button title="Go to details" />
    </View>
  );
};

export default Details;

Dessa forma, o Stack.Navigator fica assim:

TypeScript
1234567891011121314151617181920212223242526
import React from 'react';

import { NavigationContainer } from '@react-navigation/native';
import { createNativeStackNavigator } from '@react-navigation/native-stack';
import Login from './Screens/Login';
import Details from './Screens/Details';

export type RootStackParamList = {
  Login: undefined;
  Details: undefined;
};

const Stack = createNativeStackNavigator<RootStackParamList>();

function App(): React.JSX.Element {
  return (
    <NavigationContainer>
      <Stack.Navigator>
        <Stack.Screen name="Login" component={Login} />
        <Stack.Screen name="Details" component={Details} />
      </Stack.Navigator>
    </NavigationContainer>
  );
}

export default App;

Como se pode notar, foi criado um type chamado RootStackParamList e utilizado no momento de criação do Stack, sendo passado como argumento genérico do createNativeStackNavigator. Com isso, durante a definição das telas que o aplicativo possui, só podem ser considerados apenas os atributos dentro do type RootStackParamList

Isso é o suficiente? Não! Eu apenas coloquei minhas telas no Stack, porém eu não realizo nenhuma navegação entre elas.
O Stack.Screen passa para o componente um objeto navigation, que pode ser recuperado do props. Sendo assim, o componente de Login fica da seguinte forma:

TypeScript
123456789101112131415161718
import { Button, Text, TextInput, ScrollView } from 'react-native';
import { NativeStackScreenProps } from '@react-navigation/native-stack';
import { RootStackParamList } from '../App';

const Login = (props: NativeStackScreenProps<RootStackParamList>) => {
  const { navigation } = props;
  return (
    <ScrollView>
      <Text>User</Text>
      <TextInput placeholder="email" keyboardType="email-address" />
      <Text>Password</Text>
      <TextInput placeholder="password" secureTextEntry={true} />
      <Button title="Login" onPress={() => navigation.navigate('Details')} />
    </ScrollView>
  );
};

export default Login;

Olhando melhor o código do componente Login, nota-se que no onPress do Button, é utilizado o objeto navigation, que possui o metódo navigate, onde eu passo o nome da tela para qual a aplicação deve navegar.

É possível passar dados de uma tela para outra.
Primeiro, deve-se alterar o type RootStackParamList para ficar da seguinte forma:

TypeScript
1234
export type RootStackParamList = {
  Login: undefined;
  Details: { id: number };
};

Ao chamar o metódo navigate, basta passar o objeto no segundo paramêtro, por exemplo:

TypeScript
1
navigation.navigate('Details', { id: Math.random() });

Na tela de destino, dentro do props existe além do navigation, o objeto route. Exemplo:

TypeScript
123456789101112131415161718
import { NativeStackScreenProps } from '@react-navigation/native-stack';
import { View, Text, Button } from 'react-native';
import { RootStackParamList } from '../App';

const Details = (
  props: NativeStackScreenProps<RootStackParamList, 'Details'>,
) => {
  const { route } = props;
  const { id } = route.params;
  return (
    <View>
      <Text>Details {id.toString()}</Text>
      <Button title="Go to details" />
    </View>
  );
};

export default Details;

Caso a passagem de dados para outra tela seja opcional, basta mudar o type com suas telas para ficar da seguinte forma:

TypeScript
1234
export type RootStackParamList = {
  Login: undefined;
  Details?: { id: number };
};

Dessa forma, agora é possível navegar para outra tela onde a passagem de dados é opcional:

TypeScript
12345
// Passando dados
navigation.navigate('Details', { id: Math.random() });

// Sem passar dados
navigation.navigate('Details');

Além do método navigate, também existe o método push para navegar entre telas.
Qual a diferença entre eles?

  • navigate -> você abre a tela uma única vez. Ou seja, seguindo o exemplo dos slides, se eu estiver na tela de details e chamar o navigate para details
    novamente, nada vai acontecer.
  • push -> você coloca a tela no Stack de navegação quantas vezes quiser. Ou seja, se eu estiver na tela de details e chamar o push para details, ele vai adicionar mais uma tela de details no Stack.

Além dos métodos para ir para uma tela, é possível utilizar o navigate para tirar telas da pilha de navegação.

  • pop -> é um metódo para fechar a tela atual. Aceita um argumento númerico opcional para determinar, quantas telas devem ser tiradas da pilha
TypeScript
12345
// Fecha apenas a tela atual
navigation.pop();

// Fecha a tela atual e remove mais 2 telas da pilha da navegação
navigation.pop(3);
  • popToTop -> é um metódo para fechar a tela atual voltar para a primeira tela da pilha de navegação. Exemplo: se durante a navegação, você tem uma tela inicial Home que chama uma tela de Detalhes de Usuário, que dessa tela você pode abrir uma nova tela de Detalhes e assim sucessivamente, você pode voltar para a tela Home da seguinte forma:
TypeScript
12
// Fecha apenas a tela atual
navigation.popToTop();

No React Navigation existem dois hooks que são bem úteis: useNavigation e o useRoute

useNavigation -> Permite trabalhar com a atual navegação da sua aplicação
useRoute -> Permite trabalhar com os dados passados para tela atual

Exemplo de utilização do useNavigation

TypeScript
123456789101112131415161718192021
import { Button, Text, TextInput, ScrollView } from 'react-native';
import { RootStackParamList } from '../App';
import { useNavigation } from '@react-navigation/native';
import { NativeStackNavigationProp } from '@react-navigation/native-stack';

const Login = () => {
  const navigation =
    useNavigation<NativeStackNavigationProp<RootStackParamList>>();

  return (
    <ScrollView>
      <Text>User</Text>
      <TextInput placeholder="email" keyboardType="email-address" />
      <Text>Password</Text>
      <TextInput placeholder="password" secureTextEntry={true} />
      <Button title="Login" onPress={() => navigation.navigate('Details')} />
    </ScrollView>
  );
};

export default Login;

Exemplo de utilização do useRoute

TypeScript
1234567891011121314151617
import { View, Text, Button } from 'react-native';
import { RootStackParamList } from '../App';
import { RouteProp, useRoute } from '@react-navigation/native';

const Details = () => {
  const { params } = useRoute<RouteProp<RootStackParamList, 'Details'>>();
  const { id } = params;

  return (
    <View>
      <Text>Details {id.toString()}</Text>
      <Button title="Go to details" />
    </View>
  );
};

export default Details;
