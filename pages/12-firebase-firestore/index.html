Dentro do framework do Firebase, existe um recurso muito interessante chamado Firestore. Esse recurso permite que você utilize um banco de dados bem robusto. Com o Firestore, é possível trabalhar com sua aplicação até mesmo offline, pois a biblioteca tem toda a inteligência de sincronizar os dados assim que uma conexão estiver disponível. E nessa aula iremos aprender a utilizar o Firebase no projeto.











:warning: IMPORTANTE:​ Leve em consideração a configuração já feita anteriormente para ter o Firebase rodando dentro do projeto

Primeiro, acesso o console do Firebase e no menu lateral esquerdo, expanda o menu Build e dentro dele acesse a opção Cloud Firestore

Irá aparecer a página inicial do Firestore. Nessa página, clique no botão Create database

Selecione em qual região seu banco de dados ficará armazenado e clique em concluir

Na segunda etapa, será exibido as configurações do seu banco de dados. Pode utilizar o Production Mode e clicar no Next

Uma vez configurado no console do Firebase, adicione a biblioteca no projeto com o seguinte comando:

npm install @react-native-firebase/firestore









Para utilizar no código é bem simples. Basta importar a biblioteca firestore

TypeScript
1
import firestore from '@react-native-firebase/firestore';

No Firestore, tudo são coleções. Então para realizar operações CRUD (Create, Read, Update e Delete) com ele, é preciso criar uma coleção.
Para isso basta fazer o seguinte:

TypeScript
1
const collection = firestore().collection('todo');

Para adicionar um item na coleção, utilizamos o método add

TypeScript
123
await collection.add({
  name: 'minha tarefa',
});

O metódo add aceita como argumento um objeto, que pode ter qualquer estrutura que você quiser

Uma vez adicionado um objeto em uma coleção, é possível consultar no console os dados


No Firestore, cada registro é considerado um Documento. Como se pode notar, cada documento criado com o metódo add, tem um ID gerado automaticamente pela biblioteca.

Além do metódo add, também é possível utilizar o metódo set. Com o metódo set, é possível definir qual o ID do Documento

TypeScript
123
await collection.doc('qBzTlbk3waZ3ryIZsaKr').set({
  name: 'minha tarefa',
});

E quando consultado no console:


:warning: Vale ressaltar que os ID são únicos. Ou seja, se você chamar o metódo set utilizando o mesmo ID, os dados do documento são atualizados

Para obter os dados de uma coleção, basta utilizar o metódo get

TypeScript
1
const { docs } = collection.get();

Com isso, todos os itens serão obtidos de uma coleção

Caso deseja obter apenas um item, é possível definir qual documento você gostaria de obter:

TypeScript
12
const item = collection.doc('qBzTlbk3waZ3ryIZsaKr').get();
const data = item.data();

É possível aplicar filtros para obter os documentos do Firebase

TypeScript
1
const { docs } = collection.where('status', '==', 'pending').get();

Um recurso muito interessante do Firestore é acompanhar as atualizações em tempo real. É possível acompanhar em múltiplos registros ou até mesmo um único registro. Utiliza-se o metódo onSnapshot para acompanhar as modificações feitas

TypeScript
12345678
useEffect(() => {
  const subscriber = collection.onSnapshot((snapshot) => {
    setTasks(snapshot.docs);
  });

  // Stop listening for updates when no longer required
  return () => subscriber();
}, []);

No exemplo, a coleção inteira será observada. Ou seja, a atualização em qualquer documento irá disparar o evento onSnapshot

Pode-se utilizar para observar apenas registros específicos, usando uma query

TypeScript
12345678
useEffect(() => {
  const subscriber = collection
    .where('status', '==', 'pending')
    .onSnapshot((snapshot) => {
      setTasks(snapshot.docs);
    });
  return () => subscriber();
}, []);

Caso queira acompanhar as atualizações feitas em único objeto, é só informar qual documento gostaria de observar.

TypeScript
12345678910
useEffect(() => {
  const subscriber = collection
    .doc('5wZV4I2TECWo7fnPVXdH')
    .onSnapshot((snapshot) => {
      console.log(snapshot.docs);
    });

  // Stop listening for updates when no longer required
  return () => subscriber();
}, []);
