Mobile App Development

Criado em 2013 pela Meta (anteriormente Facebook), é uma biblioteca de código aberto utilizada para agilizar o desenvolvimento de interfaces de usuários através da criação de componentes.

  • Utilização de JSX (Javascript XML)
  • Single Page Application (SPA)
  • Virtual DOM (VDOM)
  • Simplicidade
  • One-way Data Binding

Para desenvolver em React, pode-se utilizar duas alternativas

  • Apenas usando arquivos estáticos
  • Utilizando o Node (recomendado)

Ao usar o Node, temos duas opções para criar o projeto. A Meta recomenda usar algum framework como o [Nextjs](https://nextjs.org/) ou o [Expo](https://expo.dev/)
Criando com o Expo
npx create-expo-app@latest <nome do projeto>

Rodando a aplicação
Execute o comando a seguir dentro da pasta do projeto

npm start

Quase tudo no React é consistido de componentes.
Existem duas abordagens de se criar componentes:

  • Classes
  • Funcional

A ideia de classe pode ser descrita como um modelo que define quais seus atributos e comportamentos para manipular os dados.

JavaScript
12345678910111213141516171819202122232425262728
import React, { Component } from 'react';

class Table extendes Component {
    render() {
        return (
            <table>
                <thead>
                    <tr>
                        <th>Name</th>
                        <th>Job</th>
                    </tr>
                </thead>
                <tbody>
                    <tr>
                        <td>Charlie</td>
                        <td>Janitor</td>
                    </tr>
                    <tr>
                        <td>Mac</td>
                        <td>Bouncer</td>
                    </tr>
                </tbody>
            </table>
        )
    }
}

export default Table;

Métodos mais importantes:
render - Define o que deverá ser exibido na tela. Implementação obrigatória
componentDidMount - Executado quando o elemento será exibido pela primeira vez
setState - Usado para atualizar o estado do componente

É a abordagem recomendada pelo próprio React. É a forma mais simples de se criar um componente, tendo em vista que é necessário apenas escrever uma
função. Para controlar o estado do componente, se utiliza o hook useState
