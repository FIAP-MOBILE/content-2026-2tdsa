Seu aplicativo pode precisar em algum momento de utilizar os recursos do sistema operacional, como a camera, lista de contatos, armazenamento, etc.
Para isso, deve ser solicitado ao usuário permissão para acessar tais recursos. O conteúdo desta aula irá detalhar como abordar e utilizar essa parte de permissões.

Uma vez instalada todas as bibliotecas, primeira precisa declarar no aplicativo quais permissões serão utilizadas.
Como iremos solicitar a permissão para utilizar camera, iremos colocar suas devidas permissões.

  • Android -> configure o arquivo AndroidManifest.xml
  • iOS -> configure o arquivo Info.plist.
  • Expo -> configure o arquivo app.json

No Android, adicione a linha de permissião da camera no arquivo AndroidManifest.xml da seguinte forma:

Após realizado as devidas configurações, no seu App.tsx coloque o seguinte código:

JavaScript
1234567891011121314151617181920212223242526272829303132333435
import React, { useEffect, useState } from "react";
import { Text, View, Button } from "react-native";

import { request, PERMISSIONS, check } from "react-native-permissions";

const App = () => {
  const [isGranted, setIsGranted] = useState<boolean>();

  const requestCameraPermission = async () => {
    try {
      const result = await request(PERMISSIONS.ANDROID.CAMERA);
      setIsGranted(result === "granted");
    } catch (error) {
      setIsGranted(false);
    }
  };

  const checkCameraPermission = async () => {
    const result = await check(PERMISSIONS.ANDROID.CAMERA);
    setIsGranted(result === "granted");
  };

  useEffect(() => {
    checkCameraPermission();
  }, []);

  return (
    <View>
      <Button title="Solicitar permissão" onPress={requestCameraPermission} />
      <Text>Permissão {isGranted ? "concedida" : "negada"}</Text>
    </View>
  );
};

export default App;

No código de exemplo, é utilizada a função request para solicitar ao usuário a permissão do usuário para acessar a camera.
Ela exige apenas um argumento, que é a permissão que será solicitada ao usuário.
Além da função request, temos também a função check, cuja implementação apenas verifica qual o status da permissão solicitada. A função check NÃO irá solicitar ao usuário permissão para acessar o recurso solicitado.
Caso queira utilizar múltiplas permissões, para evitar chamar a função check/request múltiplas vezes, existem as funções checkMultiple e requestMultiple onde aceitam uma lista de permissões a ser solicitada ao usuário.

Quando se solicita/verifica uma permissão, a mesma pode possuir diversos status. A biblioteca React Native Permissions fez uma abstração da seguinte forma:

UNAVAILABLE -> O recurso solicitado não existe no dispositivo
DENIED -> A permissão para o recurso foi negada
GRANTED -> Acesso ao recurso foi autorizado pelo usuário
LIMITED -> Acesso ao recurso foi autorizado pelo usuário, porém com limitações
BLOCKED -> O acesso ao recuso foi recusado mais de uma vez pelo usuário, causando bloqueio ao seu acesso

Um recurso interessante que a biblioteca React Native Permissions tem é a função openSettings.
Com ela, é possível direto da sua aplicação abrir a parte de configurações.

JavaScript
123456789101112131415161718192021222324252627282930313233343536373839404142434445
import React, { useEffect, useState } from "react";
import { Text, View, Button } from "react-native";

import {
  request,
  PERMISSIONS,
  check,
  openSettings,
} from "react-native-permissions";

const App = () => {
  const [isGranted, setIsGranted] = useState<boolean>();

  const requestCameraPermission = async () => {
    try {
      const result = await request(PERMISSIONS.ANDROID.CAMERA);
      setIsGranted(result === "granted");
    } catch (error) {
      setIsGranted(false);
    }
  };

  const checkCameraPermission = async () => {
    const result = await check(PERMISSIONS.ANDROID.CAMERA);
    setIsGranted(result === "granted");
  };

  const showSettings = () => {
    openSettings("application");
  };

  useEffect(() => {
    checkCameraPermission();
  }, []);

  return (
    <View>
      <Button title="Solicitar permissão" onPress={requestCameraPermission} />
      <Button title="Ver configurações" onPress={showSettings} />
      <Text>Permissão {isGranted ? "concedida" : "negada"}</Text>
    </View>
  );
};

export default App;
