Mobile App Development

Um recurso muito interessante que podemos utilizar nas aplicações é a parte de notificações. Considere que seu aplicativo está em segundo plano enquanto uma ação é executada. O usuário não vai ficar olhando toda hora o seu aplicativo. Então, uma notificação pode ser enviada para alertar o usuário.
Iremos ver nessa aula como trabalhamos com notificações

O Expo tem sua própria implementação de notificações

Instale a biblioteca com o seguinte comando:

Terminal
bash
1
npx expo install expo-notifications

Além de instalar a parte de notificações, é necessário instalar a biblioteca para fazer a compilação do projeto adequada para ser publicada nas lojas. (Play Store, App Store, etc.)

No Android, é possível criar um canal de notificações. Essa abordagem é interessante para evitar que o usuário desligue todas as notificações do seu app, segmentando o que realmente é relevante.

Primeiro, deve ser criar o canal:

TypeScript
12345
await Notifications.setNotificationChannelAsync('marketing', {
  importance: Notifications.AndroidImportance.MAX,
  name: 'Marketing',
  description: 'Mensagens de campanha de marketing',
});

Uma vez criado o canal, então é possível enviar a mensagem:

TypeScript
123456789
const notificationId = await Notifications.scheduleNotificationAsync({
  trigger: {
    channelId: 'marketing',
  },
  content: {
    title: 'Hey',
    body: 'Welcome to the app!',
  },
});

:warning: Como o iOS não tem recurso de canal de notificações, o código irá executar normalmente.

É possível atualizar uma notificação. Para isso, ao usar a função scheduleNotificationAsync, podemos informar o identifier da mesma.

Um recurso interessante é o agendamento de notificações. Com isso, você pode agendar no sistema operacional que horas a notificação será exibida.
Até o momento, todas as notificações que foram demonstradas eram ativadas instantaneamente.

Uma das formas de se agendar é passando o intervalo de tempo:

TypeScript
12345678910
const notificationId = await Notifications.scheduleNotificationAsync({

    type: Notifications.SchedulableTriggerInputTypes.TIME_INTERVAL,
    seconds: 5,
  },
  content: {
    title: 'Hey',
    body: 'Welcome to the app!',
  },
});

A notificação será enviada em 5 segundos partir do momento que ela foi registrada

Além dos eventos para saber o que acontece com a notificação, é possível definir ações que uma notificação pode ter. Esse recurso só é disponível no Android, pois ele é mais rico quanto a esse recurso.
Por padrão, se você clica na notificação, a biblioteca expo-notifications não realiza nada. Ao clicar em uma notificação, ele automaticamente vai abrir a aplicação.
O Expo define as ações como Categories. Para usar na notificação, primeiro deve-se criar a categoria:

TypeScript
12345678910
await Notifications.setNotificationCategoryAsync('reply', [
  {
    buttonTitle: 'Mark as read',
    identifier: 'REPLY_READ',
  },
  {
    buttonTitle: 'Archive',
    identifier: 'REPLY_ARCHIVE',
  },
]);

O primeiro argumento da função, setNotificationCategoryAsync é a identificação da categoria. No exemplo, foi criada uma categoria identificada como reply. Essa mesma identificação deve ser usada na notificação que deseja ter a opção de realizar ações. No código a seguir, um exemplo de como criar essa notificação:

TypeScript
123456789
const notification = await Notifications.scheduleNotificationAsync({
  identifier: notificationId,
  trigger: null,
  content: {
    title: 'Hey',
    body: 'Welcome to the app!',
    categoryIdentifier: 'reply',
  },
});

Ao criar a notificação, será exibido as ações Reply e Archive
É possível adicionar até 3 ações na notificação.

Para conseguir interagir com a notificação, é necessário registrar um listener utilizando a função
addNotificationResponseReceivedListener. Com essa função, é possível registrar um callback (chamada de retorno) onde é possível obter os dados referentes a notificação que o usuário interagiu.

TypeScript
1234567891011
useEffect(() => {
  const notificationListener =
    Notifications.addNotificationResponseReceivedListener((listener) => {
      const { actionIdentifier } = listener;
      console.log('Ação realizada', actionIdentifier);
    });

  return () => {
    notificationListener.remove();
  };
}, []);

Com o actionIdentifier, é possível saber qual ação o usuário selecionou na notificação.

Nas ações é possível utilizar uma caixa de texto onde o usuário pode digitar algo e ser capturado pelo listener. Primeiro, vamos criar as ações usando o setNotificationCategoryAsync

TypeScript
1234567891011121314
await Notifications.setNotificationCategoryAsync('reply', [
  {
    buttonTitle: 'Mark as read',
    identifier: 'REPLY_READ',
  },
  {
    buttonTitle: 'Message',
    identifier: 'REPLY_MESSAGE',
    textInput: {
      placeholder: 'Type your message',
      submitButtonTitle: 'Send',
    },
  },
]);

Agora, vamos utilizar essas ações em uma notificação:

TypeScript
123456789
const notification = await Notifications.scheduleNotificationAsync({
  identifier: notificationId,
  trigger: null,
  content: {
    title: 'Hey',
    body: 'Welcome to the app!',

Então, com o addNotificationResponseReceivedListener, vamos pegar o que o usuário digitou na caixa de entrada assim que ele clicar no botão de enviar:

TypeScript
123456789101112
useEffect(() => {
  const notificationListener =
    Notifications.addNotificationResponseReceivedListener((listener) => {
      const { actionIdentifier, userText } = listener;
      console.log('Ação realizada', actionIdentifier);
      console.log('Texto digitado', userText);
    });

  return () => {
    notificationListener.remove();
  };
}, []);

O userText contém o conteúdo digitado na caixa de entrada da notificação.

Caso o usuário interaja com uma das ações, devemos utilizar onForegroundEvent ou onBackgroundEvent.

Para capturar o que o usuário digitou, novamente deve-se utilizar onForegroundEvent/onBackgroundEvent

TypeScript
1234567
useEffect(() => {
  return notifee.onForegroundEvent(({ type, detail }) => {
    if (type === EventType.ACTION_PRESS) {
      console.log('Ação', detail.pressAction?.id, detail.input);
    }
  });
}, []);

A ideia de usar notificações é informar o usuário de forma instantanea que seu aplicativo pode te algo que exige atenção. Com isso, é importante considerar quando o aplicativo está em primeiro plano e em segundo plano.

E o que seriam esses planos?

  • Primeiro plano: O usuário está com o aplicativo aberto e visível na tela.
  • Segundo plano: O usuário não está com o aplicativo visível na tela. Ele abriu em algum momento e mudou seu foco para outro aplicativo.

Para tratar as notificações em segundo plano, é necessário instalar a biblioteca expo-task-manager.

Terminal
bash
1
npx expo install expo-task-manager

Depois de instalada a biblioteca, basta registrar sua tarefa para obter as ações da notificação que teve interação por parte do usuário

TypeScript
1234567891011121314151617181920
import * as TaskManager from 'expo-task-manager';
import * as Notifications from 'expo-notifications';

const BACKGROUND_NOTIFICATION_TASK = 'BACKGROUND-NOTIFICATION-TASK';

TaskManager.defineTask<Notifications.NotificationTaskPayload>(
  BACKGROUND_NOTIFICATION_TASK,
  async ({ data, error, executionInfo }) => {
    const hasAction = 'actionIdentifier' in data;
    if (hasAction) {
      const { actionIdentifier, userText, notification } = data;
      console.log('Action', actionIdentifier);
      console.log('User Text', userText);
      console.log('Notification', notification);
    }
    return Notifications.BackgroundNotificationTaskResult.NoData;
  },
);

Notifications.registerTaskAsync(BACKGROUND_NOTIFICATION_TASK);
