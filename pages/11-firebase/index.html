Firebase é uma biblioteca oferecida pelo Google que faz uma excelente abstração de uma série de recursos que sua aplicação pode precisar. Alguns deles são:

  • Autenticação
  • Banco de dados
  • Mensageria
  • Analytics

Para acessar sua conta gratuita, basta acessar o seguinte endereço com uma conta
Google:
https://firebase.google.com/

No topo superior direito tem o link Go To Console que vai te direcionar para o console do Firebase. Se preferir, é possível acessar o console diretamente através do link:
https://console.firebase.google.com/

Ao confirmar a criação do projeto, aparecerá uma tela mostrando que seu projeto está sendo criado

Vamos utilizar nesse primeiro momento, a parte de autenticação do Firebase.

Agora, vamos deixar o App.tsx com o seguinte código:

TypeScript
123456789101112131415161718192021222324
import React, { useState } from 'react';
import auth, { FirebaseAuthTypes } from '@react-native-firebase/auth';
import { Text, View, Button } from 'react-native';

const App = () => {
  const [user, setUser] = useState<FirebaseAuthTypes.User | null>();
  const firebaseAuth = auth();
  const doAnonymousLogin = async () => {
    const { user } = await firebaseAuth.signInAnonymously();
    setUser(user);
  };

  return (
    <View>
      {!user ? (
        <Button title="Login Anônimo" onPress={doAnonymousLogin} />
      ) : (
        <Text>User ID: {user.uid}</Text>
      )}
    </View>
  );
};

export default App;

Quando executar a aplicação, ao clicar no botão Login Anônimo, ele autenticara na plataforma do Firebase. No console, é possível verificar os usuários da sua aplicação

Utilizando o Firebase, podemos utilizar também a autenticação onde é possível utilizar email e senha. Para isso, deve-se adicionar o provedor Email/Senha no console do Firebase. No menu lateral esquerdo, na opção Build tem a sub-opção Authentication. Clique na aba Sign-in methode depois clique no botão Add New Provider

Ao clicar no botão, dentro da seção Native Providers basta selecionar Email/Password

Ao selecionar a opção Email/Password, habilite a opção Email/Password e clique no botão Save

Para criar uma conta, existe o método createUserWithEmailAndPassword

import React, { useState } from 'react';
import auth, { FirebaseAuthTypes } from '@react-native-firebase/auth';
import { Text, View, Button, TextInput } from 'react-native';

const App = () => {
  const [email, setEmail] = useState('');
  const [password, setPassword] = useState('');
  const [user, setUser] = useState<FirebaseAuthTypes.User | null>();
  const [error, setError] = useState<any>();
  const firebaseAuth = auth();

  const createAccount = async () => {
    try {
      setError(undefined);
      const { user: firebaseUser } =
        await firebaseAuth.createUserWithEmailAndPassword(email, password);
      setUser(firebaseUser);
    } catch (error) {
      setError(error);
    }
  };

  return (
    <View
      style={{
        flex: 1,
        justifyContent: 'center',
        alignItems: 'center',
      }}
    >
      <Text>Email</Text>
      <TextInput placeholder="email" onChangeText={setEmail} />
      <Text>Password</Text>
      <TextInput placeholder="password" onChangeText={setPassword} />
      <Button title="Login" onPress={doLogin} />
      {error && <Text>{error?.message}</Text>}
      {user && <Text>{user?.uid}</Text>}
    </View>
  );
};

export default App;

Ambos os métodos signInWithEmailAndPassword e createUserWithEmailAndPassword retornam uma propriedade user tem os dados do usuário autenticado. Caso ocorra alguma exceção, o error tem a propriedade message que informa qual foi o erro que ocorreu durante a requisição.

Alguns recursos interessantes que existe no Firebase são reiniciar senha e validação de
email. Para reiniciar a senha podemos utilizar o método sendPasswordResetEmail

TypeScript
123
const sendPasswordRecover = async () => {
  await auth().sendPasswordResetEmail('email@email.com`)
}

Para validar o email, o objeto user retornado quando o usuário é criado/autenticado, tem o
método sendEmailVerification. Um email é enviado para o caixa e email do usuário para qual foi solicitado a verificação

TypeScript
1234567891011
const createAccount = async () => {
  try {
    setError(undefined);
    const { user: firebaseUser } =
      await firebaseAuth.createUserWithEmailAndPassword(email, password);
    user.sendEmailVerification();
    setUser(firebaseUser);
  } catch (error) {
    setError(error);
  }
};

Um metódo que existe na instância auth é o onAuthStateChanged. Com ele é possível saber quando o estado da autenticação foi alterado.

TypeScript
123456789
const onAuthStateChanged = async (user: FirebaseAuthTypes.User | null) => {
  console.log('user changed', user);
  setUser(user);
};

useEffect(() => {
  const subscriber = auth().onAuthStateChanged(onAuthStateChanged);
  return subscriber;
}, []);
