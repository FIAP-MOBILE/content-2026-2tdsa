Mobile App Development

Na maioria das aplicações, seja mobile, web ou desktop, em algum momento queremos armazenar dados, ou como se costuma dizer, fazer persistência dos dados. E no React Native existe a biblioteca chamada Async Storage

O Async Storage é uma forma de persistência que funciona de forma assíncrona e guarda os dados usando a estrutura de chave-valor. Ele apenas armazena strings, então se precisar armazenar um dado que não seja desse tipo, é necessário fazer a conversão (serialização) para string.

Vantagens

  • Implementação muito simples
  • Documentação bem didática
  • Simples e fácil de se utilizar quando se manipula dados simples

Desvantagens

  • Não tem um bom desempenho quando se utiliza muitos dados.
  • Precisa serializar/deserializar sempre que utilizar objetos mais complexos
  • É limitado a utilizar apenas 6 MB. Pode ser configurável, mas ainda assim não é recomendado
  • Uma chave não pode ter o valor maior que 2 MB de dados

Para instalar no seu projeto, bastar rodar o comando:
npm install @react-native-async-storage/async-storage

Uma vez instalada, para utiliza-la basta importar no seu código da seguinte forma:

TypeScript
1
import AsyncStorage from '@react-native-async-storage/async-storage';

O metódo setItem serve para armazenar um valor no armazenamento local.

TypeScript
123
try {
  await AsyncStorage.setItem('chave', 'valor');
} catch (error) {}

Lembrando que se fosse um objeto, seria necessário converter ele pra string.

TypeScript
123
try {
  await AsyncStorage.setItem('chave', JSON.stringfy(objeto));
} catch (error) {}

O metódo getItem serve para retornar um valor do armazenamento local.

TypeScript
123
try {
  const value = await AsyncStorage.getItem('chave');
} catch (error) {}

Lembrando que se fosse um objeto, seria necessário converter ele pra string.

TypeScript
1234
try {
  const value = await AsyncStorage.getItem('chave');
  const data = JSON.parse(value);
} catch (error) {}

O metódo removeItem remove um valor do armazenamento local.

JavaScript
123
try {
  await AsyncStorage.removeItem('chave');
} catch (error) {}

O metódo getAllKeys retorna todas as chaves utilizadas pela sua aplicação.

JavaScript
123
try {
  const keys = await AsyncStorage.getAllKeys();
} catch (error) {}

O metódo clear remove todas as chaves utilizadas pela sua aplicação.

JavaScript
123
try {
  await AsyncStorage.clear();
} catch (error) {}

A biblioteca vem com o hook useAsyncStorage que implementa a funcionalidade de leitura, escrita e remoção.

TypeScript
12345678910111213141516171819202122232425262728293031
import React, { useState, useEffect } from 'react';
import { View, Text, Pressable } from 'react-native';
import { useAsyncStorage } from '@react-native-async-storage/async-storage';

export default function App() {
  const [value, setValue] = useState<string | null>();
  const { getItem, setItem } = useAsyncStorage('myValue');

  const readItemFromStorage = async () => {
    const item = await getItem();
    setValue(item);
  };

  const writeItemToStorage = async (newValue: string) => {
    await setItem(newValue);
    setValue(newValue);
  };

  useEffect(() => {
    readItemFromStorage();
  }, []);

  return (
    <View style={{ margin: 40 }}>
      <Text>Current value: {value}</Text>
      <Pressable onPress={() => writeItemToStorage(Math.random().toString(32))}>
        <Text>Click here to update value</Text>
      </Pressable>
    </View>
  );
}
