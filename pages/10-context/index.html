Context é um recurso do React onde podemos passar dados entre os componentes sem precisar ficar mandando props toda vez que você precisar manipular esses dados. Ou seja, é uma forma de compartilhar dados de uma forma "global".

  • Tema da aplicação
  • Configurações da aplicação
  • Autenticação
  • Configuração do usuário

Para criar um contexto, existe a função createContext.

TypeScript
123
import { createContext } from 'react';

const ThemeContext = createContext({});

O contexto tem um objeto chamado Provider.O objetivo dele é encapsular os componentes e fornecer os valores dentro do seu escopo

TypeScript

import React, { PropsWithChildren, createContext, useState } from 'react';

type ThemeType = 'light' | 'dark';
type ThemeContextProps = {
  theme: ThemeType;
  setTheme: (
    previous: ThemeType | ((previous: ThemeType) => ThemeType),
  ) => void;
};

const ThemeContext = createContext<ThemeContextProps>({} as ThemeContextProps);

const ThemeProvider: React.FC<PropsWithChildren> = ({ children }) => {
  const [theme, setTheme] = useState<ThemeType>('light');

  return (
    <ThemeContext.Provider value={{ theme, setTheme }}>
      {children}
    </ThemeContext.Provider>
  );
};

export { ThemeContext, ThemeProvider };

Conforme slide anterior, o Provider está encapsulando todo o conteúdo que estiver no children. O Provider tem uma propriedade chamada value que no exemplo é um objeto que tem as propriedades theme e setTheme.

Uma vez criado o Provider, use ele para encapsular os elementos que usarão o Context que ele fornece

Dentro do seu componente, você tem duas formas de consumir um contexto.

  • Usando o objeto Consumer que o Context possui
  • Utilizando o hook useContext









:warning: IMPORTANTE: As duas abordagens consideram que seu componente será renderizado dentro de um Provider. Se você tentar consumir o contexto fora de um Provider, ele sempre vai retornar undefined.

TypeScript
1234567891011121314151617
const MyComponent = () => {
  return (
    <ThemeContext.Consumer>
      {(value) => (
        <View
          style={{
            backgroundColor: value.theme === 'light' ? 'white' : 'black',
          }}
        >
          <Text style={{ color: value.theme === 'dark' ? 'white' : 'black' }}>
            Crie sua tarefa
          </Text>
        </View>
      )}
    </ThemeContext.Consumer>
  );
};

import { useContext } from 'react';

const MyComponent = () => {
  const { theme } = useContext(ThemeContext);
  return (
    <View
      style={{
        backgroundColor: value.theme === 'light' ? 'white' : 'black',
      }}
    >
      <Text style={{ color: theme === 'dark' ? 'white' : 'black' }}>
        Crie sua tarefa
      </Text>
    </View>
  );
};
