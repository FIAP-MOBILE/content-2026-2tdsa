Usando o Expo

Mobile App Development

Uma das alternativas de criação de aplicativos com o React Native é utilizando o Expo. O Expo é um framework que tem como base o React Native adicionando a camada web no projeto. Ou seja, além de rodar nas plataformas Android e iOS, é possível rodar a aplicação no navegador.

Para criar um projeto Expo, basta executar o seguinte comando:
npx create-expo-app demo <nome do projeto> --template blank-typescript

O argumento --template blank-typescript serve para criar um projeto com uma estrutura básica, sem muitos arquivos.

Para rodar o projeto, existem as seguintes opções:

npm run web - > Para rodar no navegador

Especificamente para rodar no navegador, é necessário instalar os seguintes pacotes:

  • react-dom
  • react-native-web
    Rode o seguinte comando para instala-los:
Code
1
npx expo install react-dom react-native-web

npm run android - > Para rodar em um dispositivo com Android
npm run ios - > Para rodar em um dispositivo com iOS

Ao usar o Expo, é interessante notar que num primeiro momento não precisa fazer instalação/configuração do Java, XCode no caso do iOS e até mesmo do Android Studio.
Só que vale ressaltar que quando precisar compilar o projeto para ser disponibilizado para a plataforma desejada (iOS ou Android) toda a configuração de ambiente é necessária.
:warning: RESUMINDO: MAIS CEDO OU MAIS TARDE, SERÁ OBRIGATÓRIO CONFIGURAR O AMBIENTE

--

Vale ressaltar outros dois pontos muito importantes:

  • Ao instalar pacotes, não se deve utilizar o npm install e sim npx expo install. Isso se deve ao fato de os pacotes para funcionar no Expo são "adaptados" para funcionar dentro do Expo. Por conta disso, nem sempre a versão mais atual do pacote é compatível com um projeto Expo
  • Muitos recursos do dispositivo, como câmera, geolocalização, permissões e etc. no Expo depende de bibliotecas exclusivas do framework. Exemplo: A biblioteca react-native-maps não tem suporte ao Expo. Então precisa usar alternativas ou fazer uma gambiarra para funcionar.
