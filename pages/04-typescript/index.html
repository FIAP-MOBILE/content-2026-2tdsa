TypeScript é uma linguagem de programação que basicamente adiciona tipagem no JavaScript. Nos permite escrever código JavaScript usando seu sistema de tipagem, permitindo identificar possíveis bugs, deixar a estrutura mais clara e ajuda na refatoração do código.
TypeScript é responsável por adicionar recursos novos no JavaScript, como arrow functions e classes, anos antes destes serem adicionados oficialmente no JavaScript.
A Microsoft desenvolveu o TypeScript e lançou publicamente em 2012.

Para utilizar TypeScript podemos instala-lo de forma global usando o node

Terminal
bash
1
npm install -g typescript

Ao instalar desse modo, você terá o comando tsc sempre disponível para ser utilizado


Ou, caso você queira configurar apenas em um projeto:

Terminal
bash
1
npm install --save-dev typescript

Usando desse modo, você também tem o comando tsc, mas deve sempre executa-lo com npx. Exemplo: npx tsc

Uma vez instalado, devemos fazer uma configuração inicial.
Isso é bem simples, basta executar o comando

Terminal
bash
1
tsc --init

Ao executar este comando, um arquivo chamado tsconfig.json onde é importante destacar algumas chaves:
compilerOptions -> outDir -> Ao compilar os arquivos, em qual diretório eles serão armazenados
compilerOptions -> module -> Qual sintaxe o projeto utilizará
compilerOptions -> target -> Para qual linguagem o projeto será compilado
include -> A lista de arquivos/diretórios que serão interpretados
exclude -> A lista de arquivos/diretórios que serão ignorados

As chaves include e exclude não vem por padrão, mas é importante ressaltar

TypeScript na verdade é só um compilador. Então nos escrevemos nosso código usando sua extensão, que é *.ts, e então compilamos para JavaScript
Vamos criar um simples arquivo chamado index.ts com o seguinte conteúdo:

TypeScript
1
console.log('Hello, world');

Dentro da pasta do seu projeto rode o comando:

Terminal
bash
1
tsc

Repare que será criado um arquivo chamado index.js
Com esse arquivo, basta rodar ele com:

Terminal
bash
1
node index.js

Quando declaramos variáveis no TypeScript, todas elas possui um tipo especifico. Essa inferência é feita no momento que declaramos a variável

TypeScript
123
let firstName = 'Leonardo'; // string
let isValid = false; // boolean
let myNumber = 10; // número

É importante ressaltar que uma vez a variável tem seu tipo definido, não é possível mudar essa tipagem

TypeScript
12
let firstName = 'Leonardo';
firstName = 10; // Compilador irá acusar um erro nesta linha

Porém, se for feito da seguinte forma:

TypeScript
123
let firstName;
fistName = 'Leonardo';
firstName = 10;

Funciona. E por que isso? Porque no TypeScript existe o tipo any, que como o nome sugere, aceita qualquer valor.

Podemos criar as variáveis com seu tipo de forma explicíta:

TypeScript
123
let firstName: string;
fistName = 'Leonardo';
firstName = 10; // Compilador irá acusar erro nesta linha

As funções no TypeScript funciona da mesma forma que no JavaScript, mas podemos tipar o seu retorno.
Podemos fazer de forma explicíta:

TypeScript
1234
function isEven(value: number): boolean {
  const result = value % 2 == 0;
  return result;
}

Se não estiver explícito na declaração da função, o TypeScript irá inferir a partir do seu retorno qual tipo será utilizado

TypeScript
1234
function isEven(value: number) {
  const result = value % 2 == 0;
  return result;
}

Caso uma função não tenha retorno, isso pode ser definido de forma explicíta utilizando a palavra void

TypeScript
123
function sayMyName(name: string): void {
  console.log(`Hello, ${name}`);
}

Neste caso, como a função não tem nenhum retorno, a utilização da palavra void é apenas para deixar mais explicíto a definição da função

Podemos definir argumentos com um valor pré-definido quando utilizamos parâmetros na função:

TypeScript
123
function sayMyName(name = 'John Doe'): void {
  console.log(`Hello, ${name}`);
}

Quando declaramos um parâmetro com seu valor pré-definido, o tipo da variável é inferido pelo TypeScript

Podemos declarar valores opcionais. Para isso, ao definir o parâmetro, basta colocar a ? na frente do seu nome.

TypeScript
123
function sayMyName(name?: string): void {
  console.log(`Hello, ${name}`);
}

Podemos definir tipagem nos Arrays de duas formas:

TypeScript
1
let fruits: string[] = ['banana', 'apple'];

Ou você pode usar Array<T> onde T é o tipo que gostaria de usar:

TypeScript
1
let fruits: Array<string> = ['banana', 'apple'];

Caso você declare um Array sem definir seu tipo, o TypeScript irá fazer a inferência a partir dos elementos.

TypeScript
1
let fruits = ['banana', 'apple']; // Array de string

As tuples são matrizes imutáveis. Ou seja, uma vez definidas, não se muda mais nada nelas.

Para declarar uma tuple, usando a seguinte sintaxe:

TypeScript
123
let myTuple: [string, string, string] = ['arg1', 'arg2', 'arg3'];

let mixedTuple: [string, number, boolean] = ['banana', 2, true];

Unions nos permite definir variáveis que podem ter múltiplos tipos.
Para isso, usamos o caracter |

TypeScript
123456789
let item: string | number;

// Pode ser atribuído um número
item = 1;
console.log(`my item ${item}`);

// Pode ser atribuído uma string
item = 'my item';
console.log(`my item ${item}`);

Se por acaso, você tem uma variável que pode ter uma múltipla tipagem,
é importante fazer a checagem para lidar com sua devida tipagem.
Veja o exemplo a seguir:

TypeScript
1234567891011
const formatValue = (value: string | number) => {
  if (typeof value === 'string') {
    console.log(value.toLowerCase());
  }
  if (typeof value === 'number') {
    console.log(value.toFixed(2));
  }
};

formatValue('Hiya');
formatValue(42);

Neste caso, se a variável foi atribuída como string, você consegue chamar os metódos relativos a esse tipo. Assim como se for do tipo number, os metódos desse tipo estarão acessíveis somente quando for definido como tal.

Usando esse tipo de recurso, é possível definir Arrays com múltipla tipagem também:

TypeScript
1
const mixedItems: (string | number)[] = ['Banana', 20, 30, 40, 'Pineapple'];

Podemos utilizar a outra forma de declarar Array

TypeScript
1
const mixedItems: Array<string | number> = ['Banana', 20, 30, 40, 'Pineapple'];

Além dos tipos primitivos, podemos definir nossos próprios tipos.
Para criar seu próprio tipo podemos usar type ou interface

TypeScript
1234
type User = {
  name: string;
  email: string;
};

O mesmo exemplo, só que usando interface

TypeScript
1234
interface User {
  name: string;
  email: string;
}

A principal diferença entre type e interface é que interface serve apenas para tipar os objetos. O type possui uma versatilidade maior.
O interface é utilizado quando queremos "forçar" o programador a ter uma melhor organização dos tipos.

Exemplo:

TypeScript
123456789101112131415
interface Feline {
  breed: string;
}

interface Cat {
  breed: 'cat';
}

type Siamese = Feline | Cat;

const myCat: Siamese = { breed: 'cat' };
console.log(`my cat ${myCat.breed}`);

const otherCat: Siamese = { breed: 'lion' };
console.log(`other cat ${myOtherCat.breed}`);

Onde definimos o tipo Siamese, isso só é possível com o type. Com o interface você não consegue usar o union.

Um ponto interessante é que a interface é que você consegue redefini-lá

TypeScript
12345678910
interface Feline {
  breed: string;
}

interface Feline {
  name: string;
}

const myCat: Feline = { breed: 'cat', name: 'Felix' };
console.log(`my cat breed is ${myCat.breed} and his name ${myCat.name}`);

Se fosse com o type o compilador acusaria um erro falando que o tipo já existe

TypeScript
12345678910
type Feline = {
  breed: string;
};

type Feline = {
  name: string;
};

const myCat: Feline = { breed: 'cat', name: 'Felix' };
console.log(`my cat breed is ${myCat.breed} and his name ${myCat.name}`);

Esse código não será compilado

Um ponto interessante é que podemos deixar os atributos com um valor pré-definido, caso você tenha necessidade

TypeScript
1234567
type User = {
  name: string;
  email: string;
  profile: 'admin' | 'manager' | 'regular';
};

const leo = { name: 'Leonardo', email: 'email@email', profile: 'regular' };

Neste exemplo, a propriedade profile só pode ter 3 possíveis valores: admin, manager, regular

E assim como podemos ter funções com parâmetros opcionais, podemos ter objetos com atributos opcionais

TypeScript
12345678
type User = {
  name: string;
  email: string;
  profile: 'admin' | 'manager' | 'regular';
  age?: number;
};

const leo = { name: 'Leonardo', email: 'email@email', profile: 'regular' };

Neste exemplo, o atributo age é opcional

Quando trabalhamos com classes funciona praticamente da mesma forma que uma tipagem:

TypeScript
1234567891011
class Person {
  name: string;

  constructor(name: string) {
    this.name = name;
  }

  sayName() {
    console.log(`say my name ${this.name}`);
  }
}

Podemos definir atributos, como está definido o name, seu devido construtor com o termo constructor e podemos definir seus metódos, que no exemplo é o sayMyName

Quando trabalhamos com classes, faz mais sentido utilizamos interface. Como citado anteriormente, uma interface força a tipagem de um objeto. Quando usamos classes, isso fica mais perceptível. Para uma classe herdar uma interface, utilizamos o termo implements

TypeScript
1234567891011121314151617
interface IPerson {
  name: string;
  email: string;
  sayName: () => void;
}

class Person implements IPerson {
  name: string;

  constructor(name: string) {
    this.name = name;
  }

  sayName() {
    console.log(`say my name ${this.name}`);
  }
}

Neste exemplo, a interface IPerson tem dois atributos (name, email e um metódo (sayMyName). A classe Person implementa a interface, porém o código não será compilado porque está faltando implementar o atributo email na classe
