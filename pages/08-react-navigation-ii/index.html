Mobile App Development

Como já vimos na aula de navegação, é possível você criar telas onde o usuário irá interagir na sua aplicação, tendo uma comunicação entre as telas através de passagem de dados para melhor sua experiência.
Nesta aula iremos ver como customizar algumas funcionalidades e como utilizar outros tipos de Stacks de navegação.

A HeaderBar é a barra que fica no topo de cada tela que é exibida na sua aplicação. Nela,
contém um título e pode ser adicionado botões de ação. A seguir, uma imagem de uma HeaderBar sem nenhuma customização

A Stack.Screen possui uma propriedade chamada options. Com essa propriedade que podemos alterar algumas propriedades da HeaderBar.
É possível alterar o título que aparece na HeaderBar. Por padrão, o título exibido quando se define name de um Stack.Screen. Para alterar o título, podemos fazer da seguinte forma:

TypeScript
12345
<Stack.Screen
  name="authors"
  component={List}
  options={{ headerTitle: 'Autores' }}
/>;

Para alterar a cor de fundo da HeaderBar, utiliza-se a propriedade headerStyle que possue apenas o backgroundColor como opção

TypeScript
12345678910
<Stack.Screen
  name="authors"
  component={List}
  options={{
    headerTitle: 'Autores',
    headerStyle: {
      backgroundColor: '#4444ff',
    },
  }}
/>;

Para alterar a cor do texto da HeaderBar, utiliza-se a propriedade headerTintColor.

TypeScript
1234567891011
<Stack.Screen
  name="authors"
  component={List}
  options={{
    headerTitle: 'Autores',
    headerTintColor: '#a1a1a1',
    headerStyle: {
      backgroundColor: '#4444ff',
    },
  }}
/>;

A propriedade headerTitle permite além de passar um string, passar um componente para renderizar no título da barra. Então levando em consideração o seguinte componente:

TypeScript
1234567891011
const HeaderTitle = ({ children }: any) => {
  return (
    <View style={{ flexDirection: 'row' }}>
      <Text style={{ fontSize: 36, color: '#ff4444' }}>{children}</Text>
      <Image
        style={{ width: 50, height: 50 }}
        source={{ uri: 'https://reactnative.dev/img/tiny_logo.png' }}
      />
    </View>
  );
};

No options do Stack.Screen, basta passar da seguinte forma:

TypeScript
1234567891011
<Stack.Screen
  name="authors"
  component={List}
  options={{
    headerTitle: (props) => <HeaderTitle {...props} />,
    headerTintColor: '#a1a1a1',
    headerStyle: {
      backgroundColor: '#4444ff',
    },
  }}
/>;

É possível adicionar botões que ficam alinhados à direita de uma HeaderBar. Para isso, utiliza-se a propriedade headerRight

1234567891011

/>

É possível customizar o botão que fica alinhado à esquerda de uma HeaderBar. Para isso, utiliza-se a propriedade headerLeft

Além da navegação utilizada com o createNativeStackNavigator, é possível utilizar outros tipos de navegação. São elas:

  • Drawer
  • Bottom Tabs
  • Material Top Tabs

É um tipo de navegação onde se utiliza as abas localizadas na parte inferior da tela. Para utiliza-la, é necessário instalar o pacote @react-navigation/bottom-tabs com o seguinte comando:

Terminal
bash
1
npm install @react-navigation/bottom-tabs

Com o Expo:

Terminal
bash
1
npx expo install @react-navigation/bottom-tabs

Assim que a biblioteca estiver instalada, pode-se utilizar a navegação por abas da seguinte forma:

TypeScript
123456789101112
import { createBottomTabNavigator } from '@react-navigation/bottom-tabs';

const Tab = createBottomTabNavigator();

const Tabs = () => {
  return (
    <Tab.Navigator>
      <Tab.Screen name="authors" component={Authors} />
      <Tab.Screen name="books" component={Books} />
    </Tab.Navigator>
  );
};

Na navegação por abas existem propriedades que podem ser utilizadas, como:
backBehavior-> Define qual o comportamento de voltar da aplicação. O padrão é firstRoute. Ainda tem as opções initialRoute, order, history e none
tabBar-> É possível customizar como a barra de navegação por abas pode ser renderizada

Na navegação por abas, é possível utilizar a propriedade screenOptions assim como na navegação convencional. Existem outras propriedades que podem ser utilizadas, como:

tabBarActiveTintColor-> Define a cor do ícone/texto da aba ativa
tabBarInactiveTintColor-> Define a cor do ícone/texto das abas inativas
tabBarActiveBackgroundColor-> Define a cor de fundo da aba ativa
tabBarActiveBackgroundColor-> Define a cor de fundo das abas inativas

O componente Screen gerado a partir de um createBottomTabNavigator tem algumas propriedades adicionais serão listadas nos próximos.

A propriedade title define qual texto será exibido no botão da aba.

TypeScript
1
<Tab.Screen name="authors" component={List} options={{ title: 'Autores' }} />;

Caso queira ocultar o texto, pode-se utilizar a propriedade tabBarShowLabel, que aceita true ou false como valores

TypeScript
12345678
<Tab.Screen
  name="authors"
  component={List}
  options={{
    title: 'Autores'
    tabBarShowLabel: false
  }}
/>

A propriedade tabBarIcon define como será renderizado o ícone da sua aba.

Para utiliza-lo, é bem similar aos outros modos de navegação

TypeScript
123456789101112

const Drawer = createDrawerNavigator();

const Home = () => {
  return (

No componente Screen podemos customizar alguns elementos da opção que será exibida no menu do Drawer, utilizando a propriedade options.
drawerLabel -> Como será exibido o elemento no menu. Pode ser um texto ou um c omponente
drawerIcon -> Renderiza um componente que será exibido a esquerda do texto
drawerActiveTintColor-> Cor do ícone/texto quando a opção estiver ativa
drawerInactiveTintColor-> Cor do ícone/texto quando a opção estiver inativa.
drawerActiveBackgroundColor-> Cor de fundo quando o item está ativo.
drawerInactiveBackgroundColor-> Cor de fundo quando o item está inativo.

Para customizar o menu lateral, deve-se utilizar o componente DrawerContentScrollView. Dentro dele, deve-se ter DrawerItem ou até mesmo um DrawerItemList

TypeScript
1234567891011121314151617181920212223
import { DrawerContentComponentProps } from '@react-navigation/drawer';

import {
  DrawerContentScrollView,
  DrawerItemList,
  DrawerItem,
} from '@react-navigation/drawer';

import { FontAwesomeIcon } from '@fortawesome/react-native-fontawesome';
import { faQuestionCircle } from '@fortawesome/free-solid-svg-icons';

const MyDrawer = (props: DrawerContentComponentProps) => {
  return (
    <DrawerContentScrollView>
      <DrawerItemList {...props} />
      <DrawerItem
        label="Help"
        icon={() => <FontAwesomeIcon icon={faSmile} />}
        onPress={() => console.log('Somebody help me')}
      />
    </DrawerContentScrollView>
  );
};

Então quando for renderizar o Drawer.Navigator, utilize a propriedade drawerContent

TypeScript
1234567891011
import { createDrawerNavigator } from "@react-navigation/drawer";
const Drawer = createDrawerNavigator();

const Home = () => {
  return (
    <Drawer.Navigator drawerContent={props => <MyDrawer {..props} />}>
      <Drawer.Screen name="authors" component={Authors} />
      <Drawer.Screen name="books" component={Books} />
    </Drawer.Navigator>
  );
};

Funciona exatamente como o BottomTabs, só que com um detalhe a mais que tem nesse tipo de navegação, é que você pode utilizar gestos para alternar entre as abas, deslizando para a direita/esquerda.

No código, basta fazer uma implementação similar aos outros navegadores:

TypeScript
1234567891011121314
import { createMaterialBottomTabNavigator } from '@react-navigation/material-top-tabs';

const Tab = createMaterialTopTabNavigator();

function App(): React.JSX.Element {
  return (
    <NavigationContainer>
      <Tab.Navigator>
        <Tab.Screen name="Login" component={Login} />
        <Tab.Screen name="Details" component={Details} />
      </Tab.Navigator>
    </NavigationContainer>
  );
}

Toda a parte de customização do componente funciona exatamente igual ao BottomTabs. Ou seja:

  • Pode-se utilizar o screenOptions no componente Navigator.
  • Pode-se utilizar o options para definir tabBarIcon, tabBarBadge, etc. no componente Screen

Todas as navegações é possível utilizar o metódo navigate do seu modo de navegação, mas não é possível utilizar o push.
Tenha isso em mente durante o desenvolvimento do seu aplicativo
